## Description

Title: Docker Container Creation — WordPress and MySQL Using Public Images

Description:

Create and configure two separate Docker containers using publicly available WordPress and MySQL images from Docker Hub. Configure the containers to communicate with each other and verify that the WordPress application connects successfully to the MySQL database.

Tasks:

- Pull the official WordPress and MySQL public images.
- Create a Docker network for communication between the containers.
- Create and configure the MySQL container with the required database name, username, and password.
- Create and configure the WordPress container with the MySQL connection details.
- Map the WordPress container port to access the application through a web browser.
- Start both containers and verify their status.
- Access WordPress through a browser and complete the initial setup.
- Verify database connectivity and document the results.
Expected Outcome:
Two running Docker containers using public images, with WordPress connected to MySQL and accessible through a web browser.

Deliverables:

- Docker commands used for image downloads and container creation.
- Container status and connectivity verification.
- Screenshot of the WordPress setup page.
- Documentation of configuration and testing results.
