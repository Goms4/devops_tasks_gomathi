## Description

Set up a Snowflake environment by creating a database, schema, and virtual warehouse. Create a table based on a given dataset, configure a CSV file format, and use an internal stage to upload and load CSV data into the table.

Implementation Tasks

1. Create a database and schema using individually assigned naming conventions.
2. Create and configure an X-Small virtual warehouse.
3. Create a table with appropriate column names and data types based on the provided dataset.
4. Create and configure a CSV file format.
5. Create an internal stage and associate it with the CSV file format.
6. Upload the provided CSV file to the internal stage.
7. Use the COPY INTO command to load data from the stage into the target table.
8. Verify the loaded records using SELECT and COUNT(*) queries.
